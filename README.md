# atmosfera 🥑

A small low-poly 3D browser simulation by [aoxilus](https://github.com/aoxilus) for a primordial planet where atoms fall from space, drift around oceans and terrain, bond into molecules, form polymer chains, and eventually produce protocells, organisms, and complex life.

## Idea

- New atoms constantly fall from space.
- The user can navigate a low-poly globe with WASD, turn with Q/E, and zoom with R/F.
- Atom distribution is Earth-inspired but tuned so life chemistry can happen during a short simulation.
- Oceans, clouds, mountains, lava vents, and meteor storms make the planet readable from near or far.
- Only nearby/visible particles are actively rendered and chemically checked.
- CHON-rich chemistry can become organic molecules and polymers.
- Polymers with phosphorus, sulfur, and energy can become protocells.
- Protocells can mutate into water life, then land/sky life.

## Run

```powershell
npm install
npm run dev
```
